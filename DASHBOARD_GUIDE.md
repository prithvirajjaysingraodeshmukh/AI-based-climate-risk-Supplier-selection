# Interactive Dashboard Guide

## Overview

The project now includes an **interactive web dashboard** built with Streamlit that provides a user-friendly interface for exploring supplier rankings and climate risk predictions.

## Features

### 📊 **Rankings Tab**
- Interactive supplier rankings table
- Filter by country, risk level, rank range, and composite score
- Sort by any column (rank, cost, quality, etc.)
- Download filtered data as CSV
- View top N suppliers (10, 25, 50, 100, or all)

### 📈 **Analytics Tab**
- **Composite Score Distribution** - Histogram showing score distribution
- **Cost vs Quality Scatter Plot** - Colored by climate risk, sized by composite score
- **Country Comparison** - Average composite scores by country
- **Lead Time Analysis** - Box plots showing lead time distribution by country

### 🌡️ **Climate Risk Tab**
- **Risk Distribution by Country** - Stacked bar chart
- **Risk Level Pie Chart** - Overall risk distribution
- **Temperature vs Rainfall** - Scatter plot with risk coloring
- **Extreme Events Analysis** - Average events by risk level

### ⚖️ **Comparison Tab**
- **Radar Chart** - Compare up to 5 suppliers across all metrics
- **Comparison Table** - Side-by-side comparison of selected suppliers
- Visual comparison of normalized scores

### ℹ️ **About Tab**
- Project overview and methodology
- Model performance information
- Usage instructions

## How to Run

### Prerequisites

1. First, run the main pipeline to generate data:
   ```bash
   python main.py
   ```

2. Install dashboard dependencies (if not already installed):
   ```bash
   pip install streamlit plotly
   ```
   Or install all dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Launch Dashboard

```bash
streamlit run app.py
```

The dashboard will automatically open in your default web browser at `http://localhost:8501`

### Using the Dashboard

1. **Filters (Sidebar)**: Use filters to narrow down suppliers by:
   - Country
   - Climate risk level
   - Rank range
   - Composite score range

2. **Key Metrics**: View summary statistics at the top

3. **Tabs**: Navigate between different views:
   - Rankings for detailed tables
   - Analytics for insights
   - Climate Risk for risk analysis
   - Comparison for supplier comparisons
   - About for project information

4. **Interactive Charts**: 
   - Hover over charts for detailed information
   - Click legend items to show/hide categories
   - Zoom and pan on scatter plots

5. **Export Data**: Use the download button in the Rankings tab to export filtered results

## Technical Details

- **Framework**: Streamlit
- **Visualizations**: Plotly (interactive charts)
- **Data Source**: `outputs/supplier_rankings.csv` (generated by `main.py`)
- **Responsive Design**: Works on desktop and tablet browsers

## Troubleshooting

**Dashboard won't start:**
- Make sure you've run `python main.py` first to generate the data files
- Check that `outputs/supplier_rankings.csv` exists
- Verify Streamlit is installed: `pip install streamlit`

**No data showing:**
- Ensure the pipeline completed successfully
- Check that output files are in the `outputs/` directory

**Charts not displaying:**
- Verify Plotly is installed: `pip install plotly`
- Check browser console for JavaScript errors
